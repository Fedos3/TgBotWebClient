# TgBotWebClient

Форк [Ajaxy/telegram-tt](https://github.com/Ajaxy/telegram-tt), адаптированный для Telegram-ботов.

Проект сохраняет опыт Telegram Web, но заменяет QR-логин и вход обычным пользовательским аккаунтом на серверную авторизацию через bot token.

English version: [README.md](README.md)

## Кратко

`TgBotWebClient` — это веб-клиент для Telegram-ботов на базе `telegram-tt`.

- Основа интерфейса: `telegram-tt`
- Модель авторизации: токен бота хранится на сервере
- Вход в панель: пароль вместо Telegram QR-логина
- Хранение данных: локальная SQLite-база
- Multi-bot режим: до 5 ботов с быстрым переключением и подключением через UI

Проект нужен, чтобы читать и отвечать пользователям бота с Mac, iPhone и из браузера, потому что отдельные клиенты для Telegram-ботов в основном существуют только на Android.

## Почему это не блокирует основной сервер бота

Панель подключается через MTProto, а основной бот обычно работает через Bot API.

Из-за этого панель не перехватывает `getUpdates` и не мешает основной бизнес-логике бота.

MTProto-клиент в этом форке использует публичные ключи Telegram Desktop из открытого исходного кода Telegram Desktop.

## Быстрый запуск

```bash
docker compose up -d --build
```

Открыть: [http://localhost:3000](http://localhost:3000)

Настройки находятся в `backend/.env`.

## Multi-bot

- Укажите `BOT_TOKEN_1` ... `BOT_TOKEN_5`
- При желании задайте названия через `BOT_LABEL_1` ... `BOT_LABEL_5`
- Первого и дополнительных ботов также можно подключать прямо из веб-интерфейса
- Все подключенные боты остаются онлайн в фоне и продолжают писать сообщения в SQLite
- Активный бот быстро переключается из левого хедера в веб-интерфейсе
